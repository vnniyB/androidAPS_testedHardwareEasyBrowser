# androidAPS_testedHardwareEasyBrowser
A beautiful way to browse https://androidaps.readthedocs.io/en/latest/Getting-Started/Phones.html#list-of-tested-phones

Hosted at https://vnniyb.github.io/androidAPS_testedHardwareEasyBrowser/

## About This Project

This project provides a modern, user-friendly web interface for browsing and filtering the community-curated list of tested phones for AndroidAPS. AndroidAPS is an open-source artificial pancreas system that requires specific hardware compatibility, and the community maintains a spreadsheet of user-tested devices and their status.

The Easy Browser fetches the latest data directly from the official Google Sheet and presents it in a searchable, filterable format. Users can easily view the list of phones as a grid of cards or a customizable data table, and filter by multiple criteria including phone brand, Android version, pump type, CGM brand, AAPS version, setup location (country), or whether the setup is verified as working.

By offering a more accessible way to explore the tested hardware list, this tool helps new and existing AndroidAPS users quickly determine which smartphone models and configurations have been successful for others in the DIY closed-loop community.
